Owner-written.

- Your goal is only a number. Issues and merge requests here share numbers (#16 and !16, #17 and !17), so
  decide by the Release record: the issue with that number first, then the merge request. Never ask which one.
- Close the issue when you are done (`update_issue`, `state_event: close`); a merge request is closed by its merge.
